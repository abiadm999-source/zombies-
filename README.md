# Rift Stand 3D

A simple static browser prototype for a 3D zombie survival game.

## Play

Open the GitHub Pages link in a browser and press the start button:

https://abiadm999-source.github.io/zombies-/

## Controls

- `1`: start 1 player
- `2`: start 2 players
- `P`: pause or resume
- `R`: restart
- Arrow keys, movement keys, and in-game keyboard controls are unchanged from the prototype

## Notes

This is a prototype build. It is prepared as a static GitHub Pages game with `index.html` at the repository root and no server or build tools required.
