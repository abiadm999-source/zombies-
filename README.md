# Rift Stand

A simple static browser prototype for a mobile 3D zombie survival game.

## Play

Open the GitHub Pages link on iPhone Safari/Chrome and press the start button:

https://abiadm999-source.github.io/zombies-/

## Controls

- Move with the left joystick
- Hold the right fire button to shoot
- Shots fire in the direction you are facing or last moved
- Keyboard controls remain as a hidden desktop/dev fallback

## Notes

This is a single-player prototype build. It is prepared as a static GitHub Pages game with `index.html` at the repository root and no server or build tools required. The previous desktop build is preserved in `golden-desktop-version.html`.
